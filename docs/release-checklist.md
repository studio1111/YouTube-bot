# Release checklist

Before every public episode:

- [ ] Topic and claims reviewed by a human.
- [ ] Source URLs, retrieval dates, and licenses recorded.
- [ ] Script, narration, visuals, captions, and metadata generated from the approved version.
- [ ] `qa_report.json` passes with no unresolved warnings.
- [ ] `provenance.json` generated and reviewed.
- [ ] Synthetic/altered media disclosure decision recorded.
- [ ] Sponsor, affiliate, and commercial claims disclosed.
- [ ] Upload package checksum matches the reviewed artifacts.
- [ ] Video uploaded privately and processing completed.
- [ ] Human watched the private result on the target device.
- [ ] Human releases or schedules it in YouTube Studio.

If any item is unclear, stop. A delayed video is cheaper than a rights, trust, or policy incident.
