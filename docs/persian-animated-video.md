# Persian voice + animated video on mobile

[**Open the Persian animated Colab**](https://colab.research.google.com/github/studio1111/YouTube-bot/blob/main/colab/yt_agent_persian_animated_video.ipynb)

این نسخه برای هر موضوع یک سناریوی فارسی کوتاه، صدای فارسی با gTTS، متن فارسی راست‌به‌چپ، ذرات متحرک، حرکت نور و خروجی MP4 واقعی می‌سازد.

1. لینک را با گوشی باز کن.
2. `TOPIC` را تغییر بده.
3. از منوی **Runtime → Run all** اجرا کن.
4. ZIP شامل ویدیو، صدای MP3، فریم‌ها، اسکریپت فارسی و manifest دانلود می‌شود.

نکته: gTTS برای ساخت صدا به اینترنت Colab نیاز دارد. اگر صدای حرفه‌ای‌تر می‌خواهی، بعداً Kokoro/Piper فارسی یا صدای ضبط‌شده خودت را به همین pipeline وصل می‌کنیم. خروجی فعلی برای prototype واقعی است، نه نسخه نهایی سینمایی.
