# Agent runbook

## Trend Tracker Talia
Finds current, source-backed ideas three times per week. It recommends topics; it does not publish.

## Quality Check Quinn
Reviews episodes on weekdays and blocks risky releases. It checks source provenance, captions, metadata, synthetic-media disclosure, and repetitive-content risk.

## Revenue Radar Riley
Reviews performance weekly and proposes one measurable revenue experiment. It never invents numbers or contacts sponsors.

## Notification Nudge Nolan
Checks delivery failures hourly and connects confirmed failures to GitHub Issues without duplicates.

All agents are advisory. Human approval remains required for factual publication, sponsor commitments, and public release.
