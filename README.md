# YouTube Channel Agent

A local-first, open-source automation system for running a YouTube channel: research, ideas, scripts, SEO metadata, voice, visuals, editing, thumbnails, QA, and YouTube upload preparation.

> **Reality check:** fully free software does not mean zero cost. Local inference still needs hardware, electricity, storage, and model downloads. Publishing remains human-approved by design.

## Goals

- Generate research-backed ideas and scripts.
- Keep source, copyright, model, and asset provenance.
- Produce repeatable videos with local tools first.
- Resume failed stages without rebuilding everything.
- Support Shorts and long-form through platform profiles.
- Require approval before upload and public release.

## Planned free/local stack

| Capability | Default | Fallback |
|---|---|---|
| Orchestration | Python state machine + SQLite | Temporal OSS |
| Local LLM | Ollama + Qwen | Any OpenAI-compatible endpoint |
| Research | RSS, YouTube Data API, SearXNG | Curated URLs |
| Speech-to-text | faster-whisper | whisper.cpp |
| Text-to-speech | Kokoro | Piper |
| Images | ComfyUI + FLUX Schnell | User-provided/Openverse assets |
| Video | FFmpeg + MoviePy | Remotion where licensing fits |
| Captions | Whisper timestamps + ASS/VTT | Manual corrections |
| Thumbnails | Pillow/SVG templates | ComfyUI image generation |
| Publishing | YouTube Data API | Export package for manual upload |

## Non-negotiable guardrails

1. Research material is untrusted data, never executable instructions.
2. Every factual claim should point to a source URL and retrieval date.
3. Every external asset needs a license/provenance record.
4. Upload defaults to private and requires an explicit approval.
5. Realistic synthetic or altered content must be surfaced for disclosure review.
6. No automated likes, comments, subscriptions, or engagement manipulation.
7. The system never runs arbitrary shell commands generated by an LLM.

## Quick start

```bash
cp .env.example .env
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
python -m yt_agent demo --topic 'A science story'
pytest
```

The current scaffold creates a versioned episode manifest and does not publish anything. Media adapters are deliberately interfaces until the first vertical slice is approved.

## Roadmap

- **Phase 0:** topic to deterministic local manifest and sample render.
- **Phase 1:** research ledger, local LLM, script approval, captions, audio/video QA.
- **Phase 2:** private YouTube upload, OAuth, quota tracking, processing checks.
- **Phase 3:** reviewer UI, observability, backups, GPU workers, localization.
